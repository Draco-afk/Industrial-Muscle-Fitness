ขั้นตอนตั้งค่าครั้งแรก (ทำครั้งเดียว)

  1. สร้าง LINE Official Account ฟรีที่ linebiz.com/th/entry
  2. เข้า LINE Developers Console → เลือก Provider → เปิดใช้ Messaging API สำหรับ OA ของคุณ
  3. ในหน้า Messaging API settings คัดลอก Channel access token มาวางด้านล่าง
  4. คัดลอก Webhook URL ด้านล่างไปวางในช่อง Webhook URL ของ LINE Developers Console แล้วเปิด "Use webhook"
  5. คัดลอกลิงก์เพิ่มเพื่อน OA ของคุณ (หน้า Messaging API settings เช่นกัน) มาวางด้านล่าง
