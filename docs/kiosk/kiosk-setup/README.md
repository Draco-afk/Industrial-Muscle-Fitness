# ตั้งค่าเครื่องตู้บริการตนเอง

เป้าหมายข้อเดียว: **ลูกค้าต้องไม่มีทางเห็นหน้าจอ Windows ของตู้** ไม่ว่าจะกดอะไรหรือเกิดอะไรขึ้น

ทำตามลำดับ 1 ถึง 5 ใช้เวลารวมประมาณ 30 นาที

---

## ป้องกันเป็นชั้น ๆ ไม่ได้พึ่งอย่างเดียว

ไม่มีวิธีไหนกันได้ครบคนเดียว จึงต้องซ้อนกันหลายชั้น ถ้าชั้นหนึ่งพลาด ชั้นถัดไปยังรับอยู่

| ชั้น | กันอะไร | ไฟล์ |
|---|---|---|
| หน้าเว็บ | คลิกขวา ลากรูป เลือกข้อความ ซูมสองครั้ง ปุ่มลัด Ctrl/Alt/F | อยู่ในหน้าเว็บแล้ว |
| Chrome kiosk | แถบที่อยู่ ปุ่มย้อนกลับ แท็บใหม่ F11 | `start-kiosk.ps1` |
| นโยบาย Chrome | เปิดเว็บอื่น เครื่องมือนักพัฒนา โหมดไม่ระบุตัวตน | `chrome-kiosk-policy.reg` |
| ตัวเฝ้า | Alt+F4 Chrome แครช โปรเซสถูกฆ่า | `start-kiosk.ps1` |
| Windows | ปัดนิ้วจากขอบจอ รีบูตจาก Windows Update | `windows-touch-lockdown.reg` |

## 1. ติดตั้ง Chrome

ดาวน์โหลดจาก google.com/chrome แล้วติดตั้งตามปกติ เปิดขึ้นมาหนึ่งครั้งแล้วปิด

## 2. ใส่นโยบาย Chrome

คลิกขวา `chrome-kiosk-policy.reg` เลือก **Merge** แล้วตอบ Yes

**ตรวจว่าเข้าจริง** เปิด Chrome พิมพ์ `chrome://policy` กด Reload policies
ต้องเห็น `URLBlocklist` และ `URLAllowlist` มีค่าอยู่

ลองเปิด google.com ต้องถูกบล็อก ลองเปิดหน้าตู้ต้องเปิดได้ปกติ

> รายชื่อโดเมนที่อนุญาต 10 รายการ ได้มาจากการเปิดหน้าเว็บจริงแล้วดูว่ามันโหลดอะไรบ้าง
> **ห้ามตัดออกเอง** ถ้าตัด `fonts.gstatic.com` ตัวหนังสือไทยจะกลายเป็นฟอนต์สำรอง
> ถ้าตัด `cloudfunctions.net` ตู้จะทำรายการไม่ได้เลย

## 3. ปิดท่าปัดนิ้วของ Windows

คลิกขวา `windows-touch-lockdown.reg` เลือก **Merge** แล้วรีสตาร์ตเครื่องหนึ่งครั้ง

ข้อนี้สำคัญกว่าที่คิด บนจอสัมผัส การปัดนิ้วจากขอบขวาเปิดศูนย์การแจ้งเตือนขึ้นมาทับ
Chrome ได้ทั้งที่ยังเต็มจออยู่ ถ้าทดสอบด้วยเมาส์อย่างเดียวจะไม่เจอปัญหานี้

## 4. ตั้งให้เปิดเครื่องแล้วเข้าตู้เอง

**4.1 ล็อกอินอัตโนมัติ**

กด `Win + R` พิมพ์ `netplwiz` กด Enter
เอาเครื่องหมายถูกหน้า "Users must enter a user name and password" ออก แล้วใส่รหัสผ่านของเครื่อง

> ผมไม่ได้ใส่รหัสผ่านลงในไฟล์ .reg ให้ เพราะมันจะไปอยู่ในรีจิสทรีแบบอ่านได้ตรง ๆ
> ใครที่เข้าถึงเครื่องได้ก็อ่านเจอ ตั้งผ่าน netplwiz ปลอดภัยกว่า

**4.2 ให้ตัวเฝ้าเริ่มพร้อมเครื่อง**

- คัดลอกโฟลเดอร์นี้ทั้งโฟลเดอร์ไปไว้ที่ `C:\ImfKiosk\`
- กด `Win + R` พิมพ์ `shell:startup` กด Enter
- คลิกขวาในโฟลเดอร์ที่เปิดขึ้นมา เลือก New → Shortcut
- วางบรรทัดนี้:

```
powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\ImfKiosk\start-kiosk.ps1"
```

- ตั้งชื่อว่า `IMF Kiosk` แล้วกด Finish

## 5. ทดสอบว่ากันได้จริง

รีสตาร์ตเครื่อง แล้วไล่ทดสอบทีละข้อ ต้องผ่านทุกข้อ

| ทดสอบ | ต้องได้ |
|---|---|
| เปิดเครื่องทิ้งไว้เฉย ๆ | เข้าหน้าตู้เองโดยไม่ต้องกดอะไร |
| เสียบคีย์บอร์ดแล้วกด Alt+F4 | จอดำแวบเดียวแล้วหน้าตู้กลับมาเอง |
| กด Ctrl+W | ไม่มีอะไรเกิดขึ้น |
| กด F11 แล้ว F12 | ไม่มีอะไรเกิดขึ้น |
| ปัดนิ้วจากขอบขวาของจอ | ไม่มีอะไรเปิดขึ้นมา |
| ปัดนิ้วซ้ายขวากลางจอ | ไม่ย้อนกลับหน้า |
| กดค้างที่ตัวหนังสือ | ไม่มีเมนูคัดลอกขึ้น |
| แตะรัว ๆ สองครั้ง | จอไม่ซูม |
| เปิด Task Manager แล้วฆ่า chrome.exe | หน้าตู้กลับมาเองใน 3 วินาที |

ถ้าข้อไหนไม่ผ่าน ดูบันทึกของตัวเฝ้าที่
`%LOCALAPPDATA%\ImfKiosk\watchdog.log`

## สิ่งที่วิธีนี้ยังกันไม่ได้

พูดตรง ๆ ไว้ก่อน จะได้ไม่เข้าใจผิดว่าปลอดภัยกว่าความจริง

**Ctrl+Alt+Del** กันไม่ได้ด้วยวิธีนี้ Windows สงวนไว้ให้ระบบเสมอ
ถ้าจะกันต้องใช้ Windows รุ่น Pro ขึ้นไปแล้วตั้ง Assigned Access
หรือง่ายกว่านั้นคือ **อย่าเสียบคีย์บอร์ดทิ้งไว้ที่ตู้** ซึ่งแก้ปัญหานี้ได้หมดในตัว

**ถ้ามีคนถอดปลั๊กหรือเปิดฝาตู้** เรื่องนี้กันด้วยซอฟต์แวร์ไม่ได้ ต้องพึ่งกุญแจตู้และการยึดตู้ติดพื้น

**Windows รุ่น Home ไม่มี Assigned Access** ถ้าซื้อ Mini PC มาแล้วเป็น Home ก็ใช้วิธีในเอกสารนี้ได้ครบ
ไม่ต้องอัปเกรดเป็น Pro

## ยิมเปิด 24 ชม.

ไฟล์ `windows-touch-lockdown.reg` ตั้งช่วงห้ามรีสตาร์ตไว้ 06:00 ถึง 23:00
ถ้ายิมเปิดตลอด ให้แก้ `ActiveHoursEnd` เป็น `dword:00000017` ไม่พอ เพราะ Windows
จำกัดช่วงนี้ไว้ไม่เกิน 18 ชั่วโมง ทางที่ดีกว่าคือตั้งเวลาให้เครื่องรีสตาร์ตเองตอนตีสาม
ผ่าน Task Scheduler ซึ่งเป็นช่วงที่คนน้อยที่สุด

## เปลี่ยน URL ของตู้

แก้บรรทัด `$Url` ใน `start-kiosk.ps1` และแก้รายการที่ `"1"` ใน `URLAllowlist`
ของ `chrome-kiosk-policy.reg` ให้ตรงกัน แล้ว Merge ใหม่
